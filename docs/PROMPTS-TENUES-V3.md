# Prompts images — toutes les tenues (style V3)

28 tenues, rangées dans l'ordre des jeux (1 à 25), puis les 3 tenues secrètes. Chaque tenue : un prompt de planche (12 stickers) et un prompt de portrait (sauf Madame Irma).

**Mode d'emploi** : joindre une image de référence du perso (sa planche de base ou une de ses planches V3), coller le prompt tel quel.
Avant d'envoyer : 12 stickers bien séparés, grosse bordure blanche partout, fond noir uni, ordre respecté.
Si les stickers se touchent : « Même planche, avec plus d'espace entre les stickers et une bordure blanche plus épaisse. »
Karo : remplacer « 10 amoureux » par « 10 charmée : cœurs dans les yeux, rougit, … ».
