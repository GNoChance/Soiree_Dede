# Événement de Noël — Lot 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Livrer avant le 1er décembre 2026 le moteur de l'événement « Noël chez Dédé » (missions du jour, Hotte du jour, flocons ❄️, Pass de Noël, Grande Hotte), son interface (carte d'accueil, page `/noel`, Hotte, célébrations), le rappel push adapté et la vidéo d'annonce.

**Architecture:** Tout le serveur en RPC SQL `security definer` (pas d'Edge Functions) : `hotte.sql` (essais + RPC de la Hotte), `hotte_banques.sql` (contenu), `noel.sql` (moteur générique d'édition, ❄️ dérivés de l'historique, récompenses idempotentes). Le front lit un seul RPC d'état `noel_state()` ; la Hotte a ses RPC `hotte_start` / `hotte_answer` / `hotte_board`. La vidéo est une composition Remotion de `promo-video/` rendue en mp4 dans `public/videos/`.

**Tech Stack:** PostgreSQL (Supabase, tests PGlite), React 19 + TS + Tailwind 4 + zustand + framer-motion, Remotion (promo-video), fonction Vercel `api/daily-reminder.ts`.

**Spec:** `docs/superpowers/specs/2026-11-24-noel-event-design.md`

## Global Constraints

- Français uniquement, tout public ; UX ultra simple, gros boutons, lisible sur mobile ; style « sticker book » (contours épais, ombre `4px 4px 0 <ink>`), thème clair + sombre.
- Édition `noel-2026` : du 2026-12-01 00:00 au 2027-01-06 23:59:59, **heure de Paris** ; « jour » = date de Paris ; date courante via `public._season_now()` (surchargée par les tests).
- Phases : `before` (avant le 1er déc), `live` (1er déc → 6 janv), `over` (7 → 13 janv : lecture seule), `off` ensuite.
- ❄️ : mission 30, bonus soirée 30, Hotte 6 × score (0-5), max 150/jour ; séries 3/7/14/21 jours → +30/+70/+140/+210 une fois par édition ; palier = `min(30, floor(❄️/150))`.
- Grande Hotte : paliers 6 000 / 14 000 / 22 000 / 30 000 / 38 000 ❄️ ; éligible si ≥ 400 ❄️ apportés.
- Invités (`profiles.is_guest`) : RPC refusées (`_require_member()` → `guest_forbidden`), jamais comptés.
- SQL idempotent, chaque fichier terminé par ses `revoke` / `grant`. Après toute modif SQL : `npm run sql` (régénère `supabase/install.sql` + `install-parts/`), rappeler à l'utilisateur de coller les morceaux modifiés dans le SQL Editor.
- Nouveaux codes d'erreur → `src/features/soiree/errors.ts`. Ne pas toucher `src/types/db.ts` (RPC appelées via le client « loose »).
- Ne jamais commiter `src/App.tsx` en entier ni les pages DEV non suivies (`GalleryPage`, `*TestPage`, `KartDuoTest`, `SpectateAuditPage`) : pour `App.tsx`, n'ajouter que les routes `/noel` et `/noel/hotte` via `git add -p`.
- Vérifs front : `npx tsc -b` (seule erreur tolérée : `src/pages/KartTestPage.tsx`), `npx eslint <fichiers>`, `npx vite build`.
- Tests SQL : `cd tools/sql-tests && node <fichier>.mjs ../../supabase/install.sql` ; suite complète avant chaque commit SQL.
- Fin de message de commit : `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` ; commit sur `main`, push après vérif.
- Ids des objets (renommés par rapport aux 1res versions de la spec, collisions) : `k_noel_traineau`, `f_noel_houx`, `f_noel_aurore`.

## Review Focus

- **Minuit à Paris** : un défi du jour fini le 5 déc à 23:30 Paris (22:30 UTC) compte pour le 5, pas pour le 6 ; une Hotte commencée à 23:58 reste celle du jour où elle a commencé → test Task 3.
- **Hotte interrompue** (appli fermée en pleine partie) : `hotte_start` rouvre le même essai avec les mêmes manches et les réponses déjà données ; passé 5 min, l'essai est clos avec le score partiel → test Task 1.
- **Deux téléphones synchronisent en même temps** : aucune récompense ni pièce en double (clé primaire des claims + `coin_ledger` unique) → test Task 4 (deux appels successifs, et un `_noel_claim` rejoué).
- **Membre jamais venu** : absent des contributeurs, non éligible, la jauge ne casse pas avec 0 ❄️ → test Task 4.
- **Hors période** : avant le 1er déc et après le 6 janv, `hotte_start` refuse (`hotte_closed`), les ❄️ ne bougent plus, `noel_state().phase` vaut `before` / `over` / `off` → tests Tasks 1 et 4.
